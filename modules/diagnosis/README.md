# 学习要求索引与作答诊断

本模块提供 `get_curriculum(dataset, { topic_id? })` 和 `diagnose_student(dataset, { student_id, node_id })`，返回统一 `team-v1` 结果。统计事实沿用数据模块的最高修订、质量隔离和节点范围；未知编号返回错误。

`diagnose_student` 的第三个可选上下文接受同次分析已计算的 `statistics` 和完整 `curriculum`，避免重复建立索引。版本或学生节点不一致、课程仅为局部主题时拒绝复用；错误结果只保留当前请求本身的统计，不返回其他对象的资料。默认调用方式仍独立计算，无跨请求缓存。

课程索引从输入课程要求、题目和材料表建立主题、指标、题目、学习卡与教材关系。课标文件页、正文页和教材正文页保留输入定位；未提供或格式不明时为 `null`。接口以 `input_index` 表明页码来自输入索引，不能把页码存在解释为本函数已核验 PDF。教材关系采用主题及材料标题匹配；未找到的材料不会补造编号。式的学习与方程、不等式之间的支持关系标为教学组织建议。

诊断结果分别标识事实、推断、证据不足和评分待复核。步骤核验使用精确有理数系数展开整式，并检查相邻线性方程、一元线性不等式的解集是否一致。支持常数、字母、加减乘、括号、除非零常数和最高六次的整数幂，可定位去括号、同类项合并、运算顺序、移项，以及不等号方向或端点的不一致。只有能够直接确认的相邻变形才产生具体步骤诊断，类型为 `expression_transformation`、`equation_transformation`、`inequality_transformation`；负数除法未变号保留 `inequality_direction`。

编号步骤、同行等号链和箭头链保留原步骤编号；可明确提取题干原式时，首个变形也与原式核对。只返回最早可确认的一处不一致，后续沿用该结果不重复计作独立根因。核验通过仅说明已检查的变形等价，不证明列式符合题意、解答完整、最终作答抄写正确或知识已掌握；有效失分事实仍保留。评分点只有在能明确关联到已确认错误时才引用，不按第一个零分点猜测根因。

变量分母、非线性方程、方程组或不等式组的整体推理、未支持记号、角色不明的引用与辨析过程，以及超过资源上限的输入，不自动判断对错。过程上限12000字符、单式512字符、128个式子、展开64项，超限时停止自动核验。有过程但能力不支持时输出 `step_analysis_unavailable` 和原因，归入 `inference`，保留有效评分；它不等同于 `insufficient_data` 的学习证据不足，也不用于生成学生薄弱点。没有过程则保留“未提供解答过程”的失分说明，不伪造步骤引用。

原始质量问题记录只产生评分复核项；如果明确步骤错误却获得相关分点分数，也产生评分复核项。该情况下保留原统计以便核对，并要求教师先确认过程和评分，不能直接用复核项推断薄弱能力。满分观察仅适用于当前已覆盖题目和指标。补充观察只针对当前节点可测而缺少有效记录的指标；未教学主题不会列作薄弱内容。

测试使用独立合成数据。设置 `STUDY_DATA_DIR` 后才核验本地赛题输入中的三主题九指标、代表学生、最新修订和材料引用；原始资料与诊断导出不纳入 Git。自动核验不能替代队员真人复验。
