# 宗博文：对比与班级分析模块交付说明

## 负责范围

宗博文负责 `modules/comparison/` 的个人与群体比较，使用魏文宇数据模块准备的当前记录、有效分值和质量标记。复验人是魏文宇，代码集成位置为 `master`。

## 可调用能力

- `compare_students`：在一个明确测验节点内，按共同有效题集比较两名学生，返回双方得分率、差值与样本证据。
- `compare_with_peers`：先排除本人，再比较目标学生与指定班级同伴群体；未指定班级时使用学生所属班级。
- `analyze_class`：返回指定班级与节点的人数、作答覆盖、有效分数汇总、主题与指标表现、学生摘要、逐题及评分点分布、复核队列和待观察指标。
- `compare_classes`：在一个明确测验节点内，按共同有效题集和相同权重比较两个班级，并保留每题实际参与人数。

跨节点观察使用 `inspect_node_pairing`，在同一学生或班级的两个节点间展示可配对题目及缺失、范围、质量原因，不计算跨节点分数差。字段和限制见[跨节点说明](README.md#跨节点观察配对)。

各函数参数与返回语义见[比较模块说明](README.md#函数)。以上四类比较与跨节点观察配对均通过统一业务 CLI 的 `run --operation` 调用，支持 JSON/CSV；`export` 生成交互报告，调用方式见[业务运行说明](../README.md)。Harness 调用使用 `--summary-only`，合成输入同时使用 `--fixture`。

## 计算与解释

比较先限定对象、节点和候选题目，再取双方共同有效题集，按每题满分占比加权。学生在同题有多个独立作答事件时，先在学生内部平均，再平均该侧学生。完整公式、差值单位、空值和复核处理见[计算口径](README.md#计算口径)。

班级摘要的 `earned_score / possible_score` 仅描述该班已观察到的有效作答样本；两班比较使用 `compare_classes` 重新选择共同题集。未教学主题单独标识，缺少观察保留为待观察，结果不用于全班能力排名，也不把不同节点的总得分率变化解释为能力进步。

## 输入与输出

输入为 `PreparedDataset`，包含已选定当前修订的记录及是否允许计分的标记。输出使用 `team-v1` 结果外壳，保留版本、请求范围、状态、证据和适用限制。复核记录可能参与计分，也可能被排除，需结合处理说明和实际比较证据查看。

JSON 与 CSV 来自同一结果，CSV 保留字段类型、空值和证据。班级结果供指导模块生成班级建议；统计摘要本身不替代诊断或教师判断。

## 验收入口

在仓库根目录运行比较测试，或执行完整业务构建与测试：

```sh
node --test modules/comparison/tests/*.test.ts
npm run study:test
```

正式数据核验需先设置本机 `STUDY_DATA_DIR`，再执行全模块复验；输入和派生结果留在本地：

```sh
sh modules/verify.sh
```

魏文宇独立核对指定同题案例、排除本人、共同题集与权重、有效人数、两人/两班切换、跨节点共同学生与不可比原因、复核提示和 JSON/CSV 一致性，并记录预期、实际、证据和结果。自动测试不替代真人复验；参与修复的条目由其他队员复验。
