## 4. 三个代表案例

### D01：部分得分

- 首要指标：T03I1。
- 焦点证据：DR0023 / Q043，当前有效版本v2，得分1/3。
- 关键步骤：移项正确；除以负数未反向；解集未核对。
- 使用题目：复习Q043，练习Q041，迁移Q042。
- 三层提示：15条，全部不含参考答案。
- 调整规则：4条。

### D14：表现较好

- 首要指标：T02I1。
- 焦点证据：Q026，将x=3误判为方程2x+1=7的解。
- 使用题目：复盘Q026，练习Q022，迁移Q034。
- 目标：由“会算”提升到“会检验、会解释”。

### D17：记录不足

- 现有证据：仅T01的4条满分记录。
- 结论：不能推断T02、T03已掌握或未掌握。
- 计划类型：coverage_probe。
- 探测题：Q022（T02I1）、Q039（T03I1）。
- 调整：只有探测后再次独立正确，才记为初步掌握。

- 模拟数据记录不完整，部分指标证据少于3条。
- 当前计划只支持教学决策，不证明真实教学成效。
- 公开GitHub分支不得包含赛题原始数据和学生作答结果；正式提交包按赛题组要求单独交付并在赛后删除。
- 如输入记录、题库或课程索引发生版本变化，必须重新生成计划。
