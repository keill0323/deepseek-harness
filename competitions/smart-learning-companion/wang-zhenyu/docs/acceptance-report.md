# 个性化建议与分步辅导模块验收报告

生成版本：1.1.0
验收日期：2026-11-15
负责人：王振宇

## 1. 验收范围

- 40名模拟学生的完整学习计划。
- 部分得分、表现较好、记录不足三类代表案例。
- 相同学生、同一目标节点内的证据使用。
- 三层学生提示与教师解析隔离。
- 真实题目、学习卡、教材和课标定位。
- 观察点、成功标准和调整条件。
- 页面、JSON、CSV同源生成。

## 2. 数据口径

| 项目 | 结果 |
|---|---:|
| 原始作答行 | 806 |
| 归并后作答事件 | 799 |
| 最高修订版本归并 | 7 |
| 已评分事件 | 790 |
| 待评分事件 | 4 |
| 未作答事件 | 5 |
| 进入自动分析的有效记录 | 793 |
| 进入人工复核的冲突记录 | 6 |

冲突处理遵循以下规则：

1. 主题、指标和满分优先与题库交叉核对。
2. 得分与有效评分点合计冲突时，可依据评分点合计导出，但记录仍标记为待复核。
3. 节点范围冲突保留原节点，不按日期、题号或记录编号自动迁移。
4. 最终作答与参考答案一致但评分为零时保留原值，只进入人工复核。
5. 所有复核记录均不进入自动辅导分析。

## 4. 三个代表案例

### 部分得分案例

- 计划目标节点：N02。
- 首要指标：T03I1。
- 复盘题、独立练习题和迁移题均来自N02允许题集。
- 三层提示只描述操作顺序、规则依据和检查方法，不给出最终结果。
- 调整规则：4条。

### 表现较好案例

- 计划目标节点：N01，显式指定为历史证据来源节点。
- 首要指标：T02I1。
- 计划聚焦检验意识和解释能力，不把单题表现扩展为全科结论。
- 学生提示通过实际泄漏检测。

### 记录不足案例

- 计划目标节点：N02。
- 现有已评分证据不足以推断当前节点掌握度。
- 计划类型：coverage_probe。
- 探测题均来自N02允许题集，并为每个指标提供三层提示。
- 只有探测后再次独立正确，才记为初步掌握。

## 6. 回归测试

运行：

```sh
node --test tests/*.test.mjs
```

当前16项测试通过，覆盖：

- 最高修订版本归并。
- 待评分和未作答不按零分。
- 同记录编号下正确零分不被自动改为满分。
- 评分点合计冲突的通用处理。
- 节点范围冲突保留原节点。
- 跨学生、跨节点、不存在题目和节点范围外题目拒绝。
- Q018类题目提示不泄露判断或结果。
- 自编整除关系题的各级提示不泄露整除结论。
- 验证器识别被篡改的证据、得分、材料和泄题提示。

## 7. 已知限制

- 模拟数据记录不完整，部分指标证据少于3条。
- 当前计划只支持教学决策，不证明真实教学成效。
- 自动分析只使用通过一致性审计且已评分的证据。
- 公开GitHub分支不得包含赛题原始数据、学生作答结果或派生明细。
- 如输入记录、题库或课程索引发生版本变化，必须重新生成计划。
