# 王振宇模块演示脚本

## 0:00—0:25 定位

“这是智慧学伴的个性化建议与分步辅导模块。它不直接给答案，而是把一条真实作答变成可执行、可调整的学习计划。”

## 0:25—1:10 D01证据链

打开D01案例，说明总分48.6%，本次聚焦T03I1。展示Q043记录：得分1/3，移项步骤得1分，除以负数反向和写解集均未得分。

## 1:10—2:05 三层提示与练习顺序

展示概念复位、Q043原题复盘、Q041独立练习、Q042迁移。展开一级、二级、三级提示，强调学生端没有直接答案。点击教师解析，展示教师端答案与完整解析单独存放。

## 2:05—2:35 调整条件

说明如果一级提示后独立完成则直接迁移；如果三级提示仍失败则回到乘除负数专项并降低难度。

## 2:35—3:05 D14与D17对比

D14展示表现较好案例的检验与迁移；D17展示记录不足案例，说明只有T01四条记录，不能推断T02、T03掌握情况，因此先补充Q022和Q039探测。

## 3:05—3:25 导出与一致性

导出学习计划JSON，说明页面、JSON、CSV共享同一版本、同一证据和同一数值来源。
