# 演示脚本（公开合成示例）

- 日期：2026-11-15
- 数据：`demo/data.example.js`，全部为合成内容
- 时长：约5分钟

## 0:00—0:25 开场

说明模块目标：把已核验证据转成可执行、可追溯、不泄题的分步辅导计划。强调真实赛题数据只在本地生成，公开演示使用合成样例。

## 0:25—1:10 部分得分案例

打开合成案例 A，展示证据链和首要指标。说明系统只使用当前学生、当前目标节点内的证据，并拒绝不存在或节点范围外题目。学生提示只展示规则、操作顺序和检查方法。

## 1:10—2:05 分步计划

依次展示概念复位、原题复盘、独立练习、迁移与检验、反思与退出。说明每一步都有成功标准以及成功/未成功后的调整动作。

## 2:05—2:35 提示安全

展示三层学生提示和教师解析隔离。说明验证器会根据当前题目参考答案实际检测提示文本，不把固定布尔值当作安全性证明。

## 2:35—3:05 表现较好与记录不足对比

合成案例 B 展示检验与迁移；合成案例 C 展示证据不足时先做低负担探测。强调缺记录不等于未掌握，待评分和未作答不按零分。

## 3:05—3:45 数据质量

展示通用一致性审计：主题、指标、满分、评分点合计、节点题集和答案键冲突。说明无法由数据本身消歧的记录保留原值并进入人工复核，不按记录编号自动改分或迁移节点。

## 3:45—4:25 导出与验证

导出计划 JSON，展示证据来源、目标节点、材料定位、调整规则和`quality_checks`。运行`node --test tests/*.test.mjs`，说明16项回归测试覆盖上下文校验与泄题检测。

## 4:25—5:00 收尾

总结：计划可执行、证据可追溯、范围可验证、冲突不静默修正。下一步由团队完成最终交叉签字、PR审核和提交包检查。
